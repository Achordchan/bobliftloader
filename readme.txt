BOBLIFT-Loader
Version: 1.0.0
Requires PHP: 8.0

Install this ZIP using WordPress > Appearance > Themes > Add New > Upload Theme.
Activate the theme, then open Tools > BOB-LIFT 站点初始化.
The explicit initialization action adds missing products, company news and pages,
sets Home as the static homepage, and enables post-name permalinks if not set.
Existing matching content is not overwritten. Search visibility is not changed.

Equipment is managed in 设备产品. News is managed in 企业新闻.
Use the WordPress editor for titles, descriptions, excerpts and featured images.
Product metadata and source fields appear below the editor.
About-page body content can be replaced using the page editor.

The enquiry form prepares an email draft for the visitor's email application.
It does not submit to a server, store leads or claim successful email delivery.

Product images and news sources are from the company's existing websites.
Confirm current specifications and public copy before production publication.
Fonts and icon license files are included in their asset directories.

Homepage and application scenes are illustrations based on real product references.
Original product photography remains in the equipment detail galleries.
