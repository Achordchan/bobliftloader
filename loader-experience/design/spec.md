# V2 多章节产品叙事

用户反馈：首屏展台感过重，滚动卡顿；需要放大看细节、更多动效、分部件介绍卖点。本轮用户要求不验证，由其自行查看。

设计：黑色整机开场 → 浅色过渡 → 履带放大 → 深色液压特写 → 白色操纵台 → 踏板近景 → 整机收尾。
每章使用自己的布局和滚动区间，不复用一个常驻首屏。
动效：标题上移、整机放大、文本显现、图片平移与缩放、标注出现、结构说明逐条展开、收尾大字展开。
素材：使用真实Blender工程渲染，新增整机、侧面、液压、操纵台四幅高清图；已有修复后踏板近景沿用。
性能：主体使用图片transform；24帧小幅环绕预先解码完毕才参与滚动，不沿用边滚边解码与最近缓存帧替代的方案。
事实：360/460共用外观、发动机不同；不编造性能指标，文案围绕可见结构。
验证：未执行。本文件记录实现意图，不代表浏览器或性能验收。
