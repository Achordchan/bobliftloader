# 履带装载机三维模型

直接用现代浏览器打开 `index.html`。运行不需要联网或安装依赖；移动文件时请保留整个文件夹。

## 多图细化版

按用户提供的整机照片、低角度侧视图和部件特写重建以下结构：

- 圆角三角履带、抬高驱动轮、轮齿、六组承重轮、内外护板、检修盖和分块胎纹。
- 折弯机罩、真实凹陷通风槽、镂空蜂窝网、六灯珠工作灯及灯框。
- 双操纵杆、锥形波纹防尘套、按钮、仪表与扶手。
- 举升臂、加强板、连接销、油缸、波纹护管、金属硬管和三路快接头。
- 中空铲斗、快换架、加强筋、侧板通孔和金属刃口。
- 侧面护板、紧固件、反光片、后部散热罩和踏板。
- 本地生成的烤漆与橡胶细微凹凸纹理，以及摄影棚环境反射。

## 操作

- 鼠标或单指拖拽：旋转；滚轮或双指手势：缩放。
- 透视、侧面、正面、背面：切换视角。
- 举升臂：0–48°；铲斗：-12–45°，可用的下翻角度随离地高度变化。
- 低举升位置限制下翻角度，避免铲刃穿过地面；举升超过 12° 时隐藏左侧标题，避免遮挡。
- 自动旋转、线框、重置：查看与恢复模型。

## 文件职责

| 文件 | 内容 |
| --- | --- |
| `index.html` | 页面入口、脚本加载、中文控制面板 |
| `style.css` | 独立页面桌面和手机布局，本轮未修改 |
| `geometry.js` | 几何工具、紧固件、材质和纹理 |
| `tracks.js` | 三角履带、轮组和履带护板；重复胎纹使用实例化绘制 |
| `body.js` | 钣金机罩、蜂窝网、灯具、控制台和后部结构 |
| `attachment.js` | 举升机构、液压系统、铲斗及姿态约束 |
| `model.js` | 组装各子系统，替换第一版集中式建模逻辑 |
| `viewer.js` | 渲染、摄影棚环境、相机与鼠标触摸交互 |
| `vendor/three.min.js` | 已有的本地 Three.js 0.160.1，未新增第三方依赖 |
| `vendor/THREE-LICENSE.txt` | 第三方 MIT 许可 |
| `*-preview.png`、`preview.png` | 当前版本的实际浏览器截图 |
