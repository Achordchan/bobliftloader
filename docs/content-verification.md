## SEO 实现

- 每个页面有唯一 title、description、自引用 canonical、Open Graph 和单一 H1。
- 公司 / 网站关联、产品、文章和面包屑输出 JSON-LD；没有虚构价格、评分或评论。
- 分类、产品、新闻详情有真实 URL 和 HTML 链接；筛选结果有空状态，搜索 / 筛选 URL 使用 noindex 并规范到对应列表页。
- 未知地址返回真正 HTTP 404，不把首页重复返回给所有 URL。
- 独立 PHP 预览提供 `/sitemap.xml` 和 `/robots.txt`；WordPress 使用核心 `/wp-sitemap.xml` 机制。
- 当前预览保持 noindex。WordPress 的搜索可见性遵从 `blog_public`；主题初始化不会擅自打开收录。

未执行正式域名部署、主站反向链接修改、Search Console 提交、Google 实际收录或排名验证。上线前需要由公司确认最终产品资料、文案、隐私政策和联系方式。
