## 本批实现

| 项目 | 实现与兼容边界 |
| --- | --- |
| C3 分组与顺序 | 首页按首屏、系列标题、系列卡片、卡片下方、应用、团队、新闻、联系排序；场景先编辑详情，再编辑列表底部询价区，详情内确认事项在推荐机型前。关于、联系的字段按模板阅读顺序整理，SEO 独立置后。产品概述含搜索描述与亮点；照片、属具、FAQ 独立成盒；正文移到规格和次要模块之前。所有 schema 路径与存储结构保持不变。 |
| C4 生效图片 | 产品和新闻用“当前生效图片”替换重复的特色图片入口，并显示来源。优先级仍是特色图片 → 备用图片；新闻还保留原主题默认图回退。备用字段放在默认收起的“备用图片”中。选择/移除只改变原特色图片关系；旧 `image` 值不被顺带清空。 |
| C5 字段说明 | 参数说明明确固定参数组与组内顺序；摘要说明不再声称产品卡片展示摘要；视频说明改为概述区独立播放器；案例概况说明改为正文上方。 |
| C6 数量上限 | `BL_CONTENT_LIMITS` 统一 FAQ 5、尺寸图 1、规格参数 40、工厂照片 3、亮点 3、属具 8、产品照片 24、图库 12、视频 8。达到上限禁用添加/未选选项，显示“前台最多显示 N 条”。**采用保留策略：保存不截断超额条目，后台标注不显示；前台读取时应用显示上限。** FAQ 不完整/重复行也有不显示说明；单产品 FAQ 在前、栏目 FAQ 补充，合计最多 5 条。 |
| C7 关联选择器 | 场景推荐机型、栏目默认属具、产品属具采用勾选与上移/下移排序。场景只提供对应产品栏目的已发布型号。CSV 字段仍保存逗号分隔字符串，产品属具仍保存数组；无效旧值以“未找到：xxx”显示且保持选中，只有主动取消才移除。 |
| C8 统一采购值 | 复用 `support.terms.warranty/lead/moq.value`；首页与 Support 的重复数字改为变量，读取时展开，不持久化展开后的文案。支持 `{warranty_months}`、`{lead_time}`、`{minimum_order}`，以及英文词形/大小写变量。与旧默认文案完全一致的历史文本在统一迁移流程中转换为变量；自定义文案原样保留，后台提示复核固定数字。默认输出逐字节不变。 |
| C9 术语 | 后台统一“额定载荷”“栏目”，可变列表不再写死“四个问题”“三步”。案例场景选择器使用当前名称，未改过的英文默认名显示中文场景名；保存的场景 slug 不变。 |
| D4 图片字段 | 列表图片 label 指向真实的 `-pick` 按钮 ID；无默认图时按钮为“移除图片”，有默认图时为“恢复默认图片”。空图片不再声称有主题默认图。 |
| D5 条件与折叠 | 翻斗车隐藏属具，集团新闻隐藏栏目；隐藏控件仍参与提交，保留值。集团新闻编辑控件直接读取后台栏目原值，避免前台过滤后的空值覆盖旧栏目。无开始日期的新闻折叠展会字段，保存保留已有名称/场馆等。产品照片、FAQ 和亮点行采用可折叠摘要。 |
| D6 未保存提醒 | 下载、统计代码、询盘邮件设置共用状态与离开提醒；媒体选择/清除派发变更事件；提交后解除提醒。 |
| 菜单 | 统计代码独立为“网站内容 → 统计代码”；仍同时要求 `manage_options` 与 `unfiltered_html`，仍通过原 `bl_content_tracking`、版本校验、锁和错误恢复流程保存。全站设置移除嵌入表单，统计保存/失败恢复返回独立页。菜单与仪表盘入口按要求排序，父 slug 保持 `bl-content-home`，所有已有 URL 保持可用。 |

菜单顺序：全站设置、首页、滑移装载机、迷你翻斗车、应用场景、采购与售后、关于我们、新闻列表、联系我们、隐私说明、未找到页面、资料下载、询盘邮件、统计代码。最后一项仅对具备原双权限者可见。
